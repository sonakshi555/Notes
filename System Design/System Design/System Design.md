1. STRATEGY Pattern
   defines a family of algorithms, encapsulates each one, and makes them interchangeable. Strategy lets the algorithm vary independently from clients that use it. 
   example : 
   - Duck is a class
   - Flying and quacking are both separates and can be taken when ever it is needed whatever it can be
   - flying : can fly have wing
     cannot fly have no wing
   - Quacking : Squeaking
     quacking
     silence
   
   
   encapsulating quacking and flying from duck superclass
