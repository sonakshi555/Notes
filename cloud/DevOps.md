What is DevOps?
- It is a culture that improves and increase the ability of delivery the product
- It's about improving delivery through
  1. Automation 
  2. Quality
  3. Monitoring
  4. Testing
Process of improving the application delivery by ensuring automation ,quality continuous monitoring [observability] and continuous testing 

Why DevOps?
***In previous ways**,* (10 - 13 years ago)
Developer -> put that in central location
System administrator -> create server
Tester -> test the application and deploy the application to the application server in server
Build and release engineer [BRE] ->move that to production

Many different fields , making the delivery period long

***Present***
One single team handle the all the above things
- adopt to new tools and technology
- to improve the efficiency of deliver of product

## **SOFTWARE DEVELOPMENT LIFECYCLE** [SDLC]

- process or culture followed by software industry to design , develop and test to deliver a high quality product and to meet the customer expectations
planning -> defining -> designing -> building -> testing -> deploy ->planning loop

Example : 
  example.com => E-commerce
Planning and requirements
- how many of them interested in this or that particular thing
- Gather requirements
Defining and Analyzing : software requirements specification document
Designing : HLD (high level design) and LLD (low level design)
- HLD : reliability ,scalability and maintenance
- LLD : designing system 
  what Db to use and all

Components that are main to DevOps  or DevOps centric are Building ,testing and deploying

Building and Implementation : 
- developing the product by writing the code 
- store in Git -> version control tool
- peer review and sharing with many people
Testing and integration :
- Application is deployed in application server 
- QE  -> quality engineer or quality assurance engineer
- QE take care to testing the software
Deployment and Maintenance : 
- Promote the application in production server to customer

DevOps engineer fastens and improves this process by without any manual intervention that is by Automation and increases the efficiency

DevOps Engineer performs :
- Kubernetes
- Docker file
- Infrastructure
- Git CI/CD
- Database setup
- manages environment

Identify the gaps in SDLC , fastening the development process , integrate security by pipeline
